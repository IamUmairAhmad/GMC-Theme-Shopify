# Storefront extras

## Wishlist, recently viewed, compare
Turn on **Theme settings > GMC: Wishlist & compare**. A heart and a Compare button appear on product cards. Add the **Wishlist**, **Recently viewed** and **Compare products** sections to pages. Data stays in the visitor's browser.

## Animations
Theme settings > animations: duration, delay, repeat when scrolling back.

## Typography and effects
Theme settings > GMC: Typography & effects: line height, letter spacing, button hover, scrollbar, custom cursor, email submit style, badge selector and same-height cards.

## Icons
Over 2,400 icons. Use the name in any icon field (for example `truck`). Common Material-style names such as `local_shipping` or `favorite` are mapped. *Filled icons* fills the shapes.

## Promo popup preview
Theme settings > GMC: Popup & marketing > Preview mode: *Testing* shows the popup on every load, *Success state* shows the thank-you state. Set it back to Off when finished.
