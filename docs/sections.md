# Sections

All GMC sections share these groups of options: *Layout (GMC)* (space, width, background colour, gradient, image or video), *Add to cart in this section*, *Slider options*, *Display on* and *Section ID and pairing*.

## Section ID and pairing
Type an ID (for example `offer`) in **Section ID** to link to it with `#offer`. To put two sections side by side, type the other section's ID in **Place beside the section with this ID**. Tick *Reverse the pair order on mobile* to swap them on phones.

## Background gradient
Enter a CSS gradient, for example `linear-gradient(135deg, #ff7a18, #af002d)`.

## Divider shapes
Section divider offers a line plus 14 shapes (diagonal, curve, triangle, zigzag, steps, waves, jagged) with flip and colour options.

## Hero and slideshow
Pagination style (dots, counter, numbers), arrow position (over, beside, below), per-device images, per-slide add to cart. The 3D parallax hero supports up to 10 layers with speed, zoom and rotation.

## Other sections
Results (percent bars), comparison table (styles, logos, tick styles), before/after slider, content tabs (icons, media, add to cart), stories (grouped by owner, verified badge, close-friends ring), music player, pricing table, shoppable image, columns (6 columns).
