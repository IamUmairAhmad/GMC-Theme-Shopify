# GMC Theme documentation

Pages, one per area. Every GMC option lives either in **Theme settings > GMC …** or in a section or block in the theme editor.

- [Product page blocks](product-blocks.md): delivery dates, checkpoints, size chart, payment badges, upsells, bundles, quantity breaks
- [Cart drawer](cart-drawer.md): progress bar, upsells, gift wrap, discount code, drawer size
- [Sections](sections.md): hero, ticker, testimonials, comparison table, tabs, stories, results and more
- [Storefront extras](storefront-extras.md): wishlist, recently viewed, compare, animations, typography, scrollbar, icons
- [Pairing sections and section IDs](sections.md#section-id-and-pairing)

Everything runs in the visitor's browser or in Liquid. No app is required.
