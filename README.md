# GMC Theme
Original Shopify theme built on Shopify's open-source Dawn (see LICENSE.md) with GMC-written sections:
ticker, icon bar, before/after slider, content tabs, quantity breaks, sticky add-to-cart, promo popup,
scroll-to-top and a free-shipping bar in the cart drawer. Configure under Theme settings > GMC features.
